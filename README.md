# Torauc for Mac

Torauc is a native Mac app for [Auctor](https://getauctor.com). This repository holds its signed, notarized releases and the app's update feed. The source code is private.

## Download

**[Download Torauc.dmg](https://github.com/scripsweave/Torauc-releases/releases/latest/download/Torauc.dmg)** (latest release)

Open the DMG and drag **Torauc** into **Applications**. You need:

- macOS 14 or newer on an Apple silicon Mac
- an Auctor account to sign in

## Updates

Torauc checks for updates when it opens and every few hours, and asks before it installs one. To check yourself, choose **Torauc ▸ Check for Updates…**. You can turn automatic checks off in **Settings ▸ Updates**.

Every release is signed with Developer ID and notarized by Apple. Each release lists SHA-256 checksums in `SHA256SUMS`.
